# 🌿 随身蒲扇

点一下扇一下，扇一下降一度。扇到 0°C 解锁隐藏彩蛋 🎉

## 在线体验

👉 **https://dadedou.github.io/palm-fan**

## 本地运行

```bash
node fanserver.js
# 打开 http://localhost:3456
```

## 功能

- 🪭 传统蒲扇造型，点击扇风动画
- 🌡️ 实时温度显示，每扇降 1°C
- ❄️ 扇到 0°C 触发冰霜特效 + 隐藏彩蛋
- 📊 每日扇风计数，零点自动重置
- 📱 移动端优化，微信内可直接打开

## 技术

纯原生 HTML/CSS/JS，零依赖，单文件部署。
